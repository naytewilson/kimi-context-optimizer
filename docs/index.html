Evidence model

Observed facts stay separate from counterfactual estimates.

The optimizer can observe what Kimi actually processed. It cannot observe provider tokenization for a file result that it prevented from being sent, so blocked-read savings remain explicitly estimated.

OBSERVED

Wire usage

Current context, cumulative input/output, cache-read input, cache creation, model identity, and recognized usage schema.

ESTIMATED

Blocked result

The exact requested text range is read from disk and converted with locally calibrated token estimation.

ESTIMATED

KCO overhead

Read-cache feedback plus notices are subtracted only when that text is actually model-visible.

estimated net direct-input reduction
  = estimated blocked-read result tokens
  - estimated model-visible block-feedback tokens
  - estimated delivered KCO notice tokens
No denominator theater: cache-read input is usage telemetry, not token savings. Replay amplification is diagnostic only. The result is not a direct measurement of Kimi subscription quota or credits, because raw tokens do not provide a public authoritative one-to-one conversion to subscription allowance.
Runtime

Optimize the hot path without narrating every breath.

High-frequency observation hooks stay silent. Actionable notices can be queued for a later model-visible phase, and their token overhead is charged only when delivered.

READ CACHE

Block unchanged repeats

Repeated covered ranges are replaced by compact structural guidance. Edits invalidate cache state. Quota mode avoids wall-clock-only expiry.

WIRE AUTHORITY

Resolve the right session

Session-index authority prevents a newer unrelated transcript from contaminating the current session's usage accounting.

SCHEMA DOCTOR

Detect drift

A reachable wire file is not enough. Doctor requires recognized usage rows before calling the transcript supported.

QUOTA SIGNAL

Compact on replay pressure

Context size, step count, and replay amplification can trigger an early compact recommendation without pretending the signal equals credits saved.

PROMPT COACH

Charge what you inject

Model-visible coaching is included in the delivered-notice overhead ledger instead of being treated as free advice from the heavens.

CONTEXT SHIELD

Learn historical waste

Repeated unused-read patterns can suggest context-ignore rules, labeled as estimated historical read volume rather than guaranteed future savings.

Synthetic Counterfactual Benchmark

A benchmark that admits what it is.

The repository benchmark uses deterministic fixture files and the same gross-minus-overhead accounting identity as runtime. It measures an estimated counterfactual direct-input reduction for those fixtures.

IT DOES

Subtract KCO's own feedback

  • Uses actual fixture text ranges.
  • Subtracts model-visible block feedback.
  • Preserves negative net values if overhead wins.
  • Emits machine-readable results with classification ESTIMATED.
IT DOES NOT

Invent causal certainty

  • No replay multiplier in the savings claim.
  • No cache-read tokens counted as avoided input.
  • No conversion to Kimi subscription credits.
  • No synthetic percentage marketed as live-session truth.
Install

Point Kimi Code at the hardened fork.

Requires Node.js 18 or newer. After updating the checkout, reinstall and reload because Kimi runs a managed plugin copy.

/plugins install https://github.com/naytewilson/kimi-context-optimizer
